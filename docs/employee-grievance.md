# Employee grievance

Employee grievance is an internal, authenticated employee-rights and workplace/administrative process. It is implemented in the `grievances` domain and is not a public complaint channel.

The current workflow supports draft and formal submission, intake, configured routing, panel snapshots, recusals, evidence, hearings, decision versions, approvals, correspondence, delivery acknowledgement, employee appeal, audit, notifications, private storage, organization scope, and working-day SLA snapshots.

The employee identity and current assignment are captured from the authenticated account. The module must not accept a browser-supplied applicant identity as authoritative. Grievance routes, deadlines, categories, quorum, voting, retention, and appeal settings are configurable; values currently marked as defaults remain policy configuration rather than claims about Regulation 201/2018.

The current portal is `My Grievances`. It must not surface public QR feedback, suggestions, or complaints.

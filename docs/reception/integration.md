# Reception integrations

Reception reads Core organizations, current units, users, employees and the organization-design service catalog. It uses platform code rules for desk codes, the shared audit writer for material changes, the work calendar for appointments, and the shared Inertia/localization shell.

Employee/card verification, support tickets, grievances, cafeteria and transport remain owner workflows. Reception records a service/referral pointer; it never creates their transactions or bypasses their policies.

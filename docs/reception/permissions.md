# Reception permissions

- `reception.view`: scoped dashboard, visits, queue and published service directory.
- `reception.operate`: check-in, queue transitions and referrals.
- `reception.supervise`: operational supervision capability.
- `reception.configure`: desks, counters, supported services and staff.
- `reception.appointments.manage`: appointment lifecycle.
- `reception.reports.view` / `reception.reports.export`: scoped analytics and audited export.
- `reception.audit`: read-only historical review.

Default scoped roles are Reception Administrator, Reception Supervisor, Reception Officer and Information Officer. The existing Auditor receives view/report/audit only. Permissions never replace organization scopes.

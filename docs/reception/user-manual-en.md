# Reception user manual

Open **Reception & Information Desk**. Use **Register visitor** for a walk-in, collect only the minimum information, choose the correct institution/desk, and check in. From **Today's visitors**, issue a ticket. In **Queue management**, call, recall, start and complete the ticket in order. Use **Service directory** for approved information and **Referrals** to review routed visits. Administrators configure desks and counters only inside their assigned organization scope. Reports can be exported only by authorized roles; downloads are audited.

# Reception workflows

## Walk-in

Register or find minimal visitor → create checked-in visit → issue daily ticket → call → start service → complete, cancel, mark no-show, or refer.

## Appointment

Create future working-day booking → locate by reference → check in → link visit → proceed through the same queue and outcome workflow. Booking conflicts are rejected by a database unique constraint.

## Referral

Choose an authorized destination organization/unit and canonical service → record reason and sender → mark visit referred → destination acknowledges and records outcome in a later extension without changing earlier chain entries.

# 02 · የተቋም መዋቅር

**ለማን፡** ለከተማ አስተዳደር የመዋቅር ባለሙያዎች፣ ለተቋም የሰው ሀብት ኃላፊዎች (በራሳቸው ተቋም ወሰን)።

**ዓላማ፡** የከተማው ተቋማት፣ የሥራ ክፍሎቻቸውና የተጠሪነት መስመሮቻቸው በአንድ ጸድቆ የተመዘገበ መዋቅር ውስጥ እንዲቀመጡ፤ ሌሎች ሞጁሎች ሁሉ (ሠራተኛ፣ መደብ፣ ቅሬታ፣ አስተያየት) በዚህ መዋቅር ላይ ይመሠረታሉ።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| ተቋማት | የተመዘገቡ ተቋማት ዝርዝር፣ ኮድ፣ ዓይነት፣ ሁኔታ፣ የበላይ ተቋም። የአዋጅ 94/2019 ተቋማት በአማርኛ ኮድ ተመዝግበዋል። |
| የተቋም ዓይነቶች | ቢሮ፣ ኤጀንሲ፣ ክፍለ ከተማ፣ ወረዳ ወዘተ፤ ለተዋረዱ ሕጎች። |
| የሥራ ክፍሎች | በተቋም ውስጥ ያሉ ክፍሎች (ዳይሬክቶሬት፣ ቡድን...) እና የእነሱ ዛፍ። |
| የሥራ ክፍል ዓይነቶች | የክፍል ደረጃዎች። |
| የመዋቅር ስሪቶች | እያንዳንዱ የመዋቅር ለውጥ ስሪት ነው፤ "እንደ ቀን" (as-of) ማየትና ሁለት ስሪቶችን ማወዳደር ይቻላል። የጸደቀ ስሪት አይቀየርም። |
| የለውጥ ጥያቄዎች (የእኔ / ግምገማ / ትግበራ / የተጠናቀቁ) | የመዋቅር ለውጥ (ክፍል መክፈት፣ መቀላቀል፣ ማዛወር) በጥያቄ፣ በግምገማ፣ በጸደቀ ትግበራ ይጓዛል። |
| የተጠሪነት መስመሮች | ማን ለማን ያሳውቃል፤ የሥራ መደብ ላይ የተመሠረተ፣ ከጊዜያዊ ውክልና ጋር ([04](04-employee-management.md))። |

## ተደጋጋሚ ሥራዎች

**አዲስ ተቋም መመዝገብ**
1. ተቋማት › አዲስ። ኮድ፣ ስም (አማርኛ/English)፣ አጭር ስም፣ ዓይነት፣ የበላይ ተቋም፣ አድራሻና ስልክ።
2. የተቋሙ ኃላፊ የሥራ መደብ ከቅጹ ይፈጠራል (የሥራ ክፍል ሳይኖረው ይፈቀዳል)።
3. "አስቀምጥ" — የመዋቅር ስሪት በራስ-ሰር ይፈጠራል። ስህተት ከሆነ "መመዝገቡን ሰርዝ" ከቀናት ውስጥ ይቻላል፤ ሠራተኛ ከተመደበ በኋላ አይቻልም።

**የሥራ ክፍል መክፈት ወይም ማዛወር**
1. የለውጥ ጥያቄዎች › አዲስ ጥያቄ፡ የለውጡ ዓይነት፣ ምክንያት፣ የሚጀምርበት ቀን።
2. የሚገመግመው ክፍል ያጸድቃል ወይም ይመልሳል።
3. በጸደቀው ቀን "ትግበራ" ይጫናል፤ አዲስ የመዋቅር ስሪት ይወጣል፤ የነበሩት ምደባዎች ይከተላሉ።

**መዋቅር ከ Excel መጫን**
1. ተቋማት › አስመጣ (Import)። የአብነት ፋይሉን ያውርዱ፣ ይሙሉ፣ ይጫኑ።
2. ሥርዓቱ መጀመሪያ ያረጋግጣል (የጎደለ ኮድ፣ የተደጋገመ ስም፣ ያልታወቀ የበላይ) ከዚያም ይመዘግባል። የተሳሳተ ረድፍ ካለ ምንም አይመዘገብም።

## ደንቦች ማወቅ ያለብዎት

- አንድ ተቋም ከአንድ የበላይ ተቋም በላይ ሊኖረው አይችልም፤ ዑደት (A የ B፣ B የ A የበላይ) አይፈቀድም።
- ሠራተኛ ወይም የሥራ መደብ የተመደበበት ክፍል ወይም ተቋም አይሰረዝም፤ መጀመሪያ ያዛውሩ።
- የመዋቅር ስሪት ከጸደቀ በኋላ አይስተካከልም፤ አዲስ ስሪት ያውጡ።
- በተቋም ወሰን ያለው ተጠቃሚ የራሱን ተቋምና የሥሩን ብቻ ያያል።

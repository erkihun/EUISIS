# 03 · የሰው ኃይል መሠረታዊ መረጃ

**ለማን፡** ለሰው ሀብት ባለሙያዎች (የሥራ መደብ አስተዳደር)፣ ለከተማ ደረጃ የመደብ ባለሙያዎች።

**ዓላማ፡** ሠራተኛ ከመመደቡ በፊት የሥራ መደቡ፣ ደረጃው እና ሙያው በአንድ የጸደቀ መዝገብ ውስጥ እንዲኖር። ሁሉም ምደባ፣ ክፍት የሥራ መደብ ማስታወቂያ እና የአፈጻጸም ዕቅድ ከዚህ ይነሳል።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| የሥራ መደቦች | የተቋሙ መደቦች፡ ኮድ፣ ርዕስ፣ ክፍል፣ ደረጃ፣ ሙያ፣ ሁኔታ (ክፍት/የተያዘ/የታገደ)። |
| የሥራ መደቦች ሁኔታ | የአዲስ መደቦች የመጽደቅ ደረጃ። |
| የጸደቁ የሥራ መደቦች | የመደብ ብዛት ማቋቋሚያ (establishment)፡ ለአንድ ርዕስ ስንት መደብ እንደጸደቀ፣ ስንቱ እንደተያዘ። |
| የሥራ መደብ አገልግሎቶች | አንድ መደብ ለሕዝብ የሚሰጣቸው አገልግሎቶች፤ የተገልጋይ አስተያየት QR በዚህ ይገናኛል። |
| የሥራ ደረጃዎች | የደረጃ መዋቅር (grade levels)። |
| የሙያ ምድቦች (ISCO) | የ ISCO-08 ሙያዎች በአማርኛና በእንግሊዝኛ፤ ለእያንዳንዱ መደብ አንድ ሙያ ይመረጣል። |
| የኢኮኖሚ ዘርፍ ምደባ (ISIC) | የ ISIC Rev.4 ዘርፎች፤ ለተቋማት ምደባ። |

## ተደጋጋሚ ሥራዎች

**አዲስ የሥራ መደብ መክፈት**
1. የሥራ መደቦች › አዲስ። የመደብ ኮድ በኮድ ደንብ በራስ-ሰር ይመጣል (ወይም ባለቤት/አስተናጋጅ ቅርጸት)።
2. ርዕስ፣ የሥራ ክፍል፣ ደረጃ፣ የ ISCO ሙያ፣ የሥራ መግለጫ።
3. የጸደቀ ማቋቋሚያ ከሌለው መደቡ "በመጠባበቅ ላይ" ይሆናል፤ ማቋቋሚያው ሲጸድቅ ክፍት ይሆናል።

**ማቋቋሚያ (establishment) ማጽደቅ**
1. የጸደቁ የሥራ መደቦች › አዲስ ማቋቋሚያ፡ ርዕስ፣ ብዛት፣ የጸደቀበት ሰነድ።
2. ያጸደቀው ሰው ስምና ቀን ይመዘገባል። ከጸደቀው ብዛት በላይ መመደብ አይቻልም።

**የመደብ አገልግሎቶች ማስመዝገብ**
1. የሥራ መደብ አገልግሎቶች › መደቡን ይምረጡ › አገልግሎት ይጨምሩ (ከአገልግሎት ካታሎግ)።
2. የአገልግሎት ቁጥር (service no.) ይሰጣል፤ የሕዝብ አስተያየት ቅጽ በዚህ ቁጥር ይለያል።

## ደንቦች

- አንድ መደብ በአንድ ጊዜ ከአንድ ሠራተኛ በላይ አይያዝም (ተጠባባቂ ምደባ ካልሆነ)።
- ሙያ ያልተመረጠለት መደብ ለምዘና እና ለአፈጻጸም ዕቅድ አይቆጠርም።
- የ ISCO እና ISIC ዝርዝሮች ከተቋም ውጪ ናቸው፤ የሚቀይራቸው የከተማ ደረጃ አስተዳዳሪ ብቻ ነው።

# 04 · የሠራተኛ አስተዳደር

**ለማን፡** ለሰው ሀብት ባለሙያዎችና ኃላፊዎች (በተቋማቸው ወሰን)፣ ለከተማ ደረጃ የሠራተኛ መዝገብ ባለሙያዎች።

**ዓላማ፡** የእያንዳንዱ የመንግሥት ሠራተኛ አንድ ትክክለኛ መዝገብ፡ ማንነት፣ ቅጥር፣ ምደባ፣ የተጠሪነት መስመር፣ ፎቶና ሰነዶች። ሌሎች ሞጁሎች ይህን መዝገብ ያነባሉ እንጂ አይደግሙትም።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| ሠራተኞች | ዝርዝር፣ ፍለጋ፣ ማጣሪያ፣ የመዝገብ ገጽ (ትሮች፡ ማንነት፣ ቅጥር፣ ምደባዎች፣ ሰነዶች፣ ካርድ፣ ታሪክ)። |
| የሠራተኞች CSV ይጫኑ | ብዙ ሠራተኞችን በአንድ ጊዜ ከ CSV መመዝገብ፤ መጀመሪያ ማረጋገጫ፣ ከዚያ ምዝገባ። |
| የክፍት የሥራ መደብ ማስታወቂያዎች / ማመልከቻዎች | የውስጥ ቅጥር ማስታወቂያ ማውጣት፣ ማመልከቻዎችን መመልከትና መምረጥ። |
| ማመልከቻዎቼ | ሠራተኛው ራሱ ያቀረባቸው የክፍት መደብ ማመልከቻዎች። |
| የተጠሪነት ተዋረድ | የተቋሙ የተጠሪነት ዛፍ፡ ማን ለማን ያሳውቃል፣ በመደብ ላይ የተመሠረተ። |
| ተጠባባቂ ሹመቶች | ኃላፊ በሌለበት ጊዜ የተሾመ ተጠባባቂ፣ ከጊዜ ገደብ ጋር። |
| የኃላፊ ውክልናዎች | ኃላፊ ለሌላ ሰው የሚሰጠው ጊዜያዊ ሥልጣን (ለምሳሌ ዕለታዊ እንቅስቃሴ ማጽደቅ)፣ ከመጨረሻ ቀን ጋር። |

## ተደጋጋሚ ሥራዎች

**አዲስ ሠራተኛ መመዝገብ**
1. ሠራተኞች › አዲስ። የሠራተኛ መለያ ቁጥር በኮድ ደንብ ይመጣል።
2. ማንነት፡ ስም (በሦስት ክፍል)፣ ጾታ፣ የትውልድ ቀን (የኢትዮጵያ ቀን መጻፍ ይቻላል)፣ ብሔራዊ መታወቂያ ቁጥር (ይመሰጠራል)፣ ፎቶ።
3. ቅጥር፡ የቅጥር ዓይነት፣ የአገልግሎት መጀመሪያ ቀን፣ የትምህርት ደረጃ።
4. ምደባ፡ ተቋም፣ የሥራ ክፍል፣ የሥራ መደብ (ክፍት መሆን አለበት)፣ የሚጀምርበት ቀን።
5. "አስቀምጥ"። መዝገቡ "የተረጋገጠ" ደረጃ ላይ እስኪደርስ (ሰነዶች እስኪገመገሙ) መታወቂያ ካርድ አይወጣለትም።

**ምደባ መቀየር (በተቋም ውስጥ)**
1. የሠራተኛ መዝገብ › ምደባዎች › አዲስ ምደባ። አሮጌው ምደባ በራስ-ሰር ይዘጋል፤ ታሪኩ ይቀመጣል።
2. ወደ ሌላ ተቋም ከሆነ የዝውውር ሞጁሉን ይጠቀሙ ([11](11-transfer.md))።

**የ CSV ምዝገባ**
1. የሠራተኞች CSV ይጫኑ › አብነቱን ያውርዱ። ዓምዶቹን አይቀይሩ።
2. ፋይሉን ይጫኑ › "አረጋግጥ"። ስህተት ያለባቸው ረድፎች ከምክንያታቸው ጋር ይታያሉ (የተደጋገመ መለያ ቁጥር፣ ያልታወቀ የሥራ መደብ ኮድ፣ የተሳሳተ ቀን)።
3. ሁሉም ረድፎች ሲጸዱ "መዝግብ"። ከፊል ምዝገባ የለም።

**ተጠባባቂ ኃላፊ መሾም**
1. ተጠባባቂ ሹመቶች › አዲስ፡ የሥራ መደብ፣ ተጠባባቂው ሠራተኛ፣ ከ–እስከ ቀን፣ ምክንያት።
2. በዚያ ጊዜ ውስጥ የተጠሪነት መስመር፣ የማጽደቅ ወረፋዎችና ማሳወቂያዎች ወደ ተጠባባቂው ይሄዳሉ፤ ቀኑ ሲያልፍ ይመለሳል።

## ደንቦች

- የማንነት መስኮች (ስም፣ የትውልድ ቀን፣ ብሔራዊ መታወቂያ) ከተረጋገጡ በኋላ በቀጥታ አይስተካከሉም፤ በ "የሠራተኛ ማስተካከያ" ጥያቄ (ከማስረጃ ጋር) ብቻ።
- አንድ ሠራተኛ አንድ ወቅታዊ ምደባ ብቻ አለው።
- የሠራተኛ ፎቶ በግል ማከማቻ ይቀመጣል፤ የሚያየው ፈቃድ ያለው ብቻ ነው።
- ሠራተኛ መሰረዝ ወደ "የተሰረዙ መዝገቦች" ይወስዳል፤ ቋሚ መሰረዝ የተለየ ፈቃድና ምክንያት ይፈልጋል፣ ይመዘገባል።
- ሠራተኛው ራሱ ስልክ/ኢሜይሉን በ My Portal ይቀይራል፤ ለዚያ የሰው ሀብት አያስፈልግም።

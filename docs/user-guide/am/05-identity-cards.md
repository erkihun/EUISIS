# 05 · መታወቂያ ካርዶችና NFC

**ለማን፡** ለመታወቂያ ክፍል ባለሙያዎች፣ ለሕትመት ጣቢያ ኦፕሬተሮች፣ ለ NFC ተርሚናል አስተዳዳሪዎች።

**ዓላማ፡** ለእያንዳንዱ የተረጋገጠ ሠራተኛ አንድ ሕጋዊ ካርድ፣ በሕዝብ ገጽ የሚረጋገጥ የማይቀየር QR፣ ለካፌቴሪያና ትራንስፖርት የሚያገለግል NFC ማረጋገጫ።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| መታወቂያ ካርዶች | ሁሉም ካርዶች፣ ሁኔታ (በሕትመት ላይ፣ የታተመ፣ የተሰጠ፣ ንቁ፣ የጠፋ፣ የተበላሸ፣ የታገደ፣ የተሰረዘ፣ ያለፈበት፣ የተተካ)። |
| እንደገና ማተም ያስፈልጋል | ፎቶ ወይም ስም የተቀየረባቸው ካርዶች። |
| የካርዶች የጅምላ ሕትመት / የሕትመት ዙሮች | ብዙ ካርዶችን በአንድ ዙር ማዘጋጀት፣ PDF ማውጣት፣ የጥራት ፍተሻ፣ "ታተመ" ማለት። |
| የመታወቂያ ካርድ አብነቶች | የካርዱ ንድፍ (የተቋም አርማ፣ ቀለም፣ መስኮች)። ዲጂታል መታወቂያው የመስጫ/የማለፊያ ቀን አያትምም። |
| የሠራተኛ ማስተካከያዎች | ካርድ ከመታተሙ በፊት የሚስተካከሉ የማንነት ጥያቄዎች። |
| የካርድ ጥያቄዎች | ሠራተኞች ያቀረቧቸው የመጥፋት/የመበላሸት/የምትክ ጥያቄዎች። |
| የNFC አስተዳደር / ማረጋገጫዎች / ተርሚናሎች / መዝገቦች | የ NFC ካርድ ማረጋገጫዎችን መስጠትና መሰረዝ፣ ተርሚናሎችን መመዝገብ፣ የማረጋገጫ ሙከራዎችን ማየት። |

## ተደጋጋሚ ሥራዎች

**ካርድ ማውጣት (ከሠራተኛ ምዝገባ በኋላ)**
1. ሠራተኛው "የተረጋገጠ" መሆን አለበት፤ ፎቶ ሊኖረው ይገባል።
2. መታወቂያ ካርዶች › አዲስ ካርድ (ወይም በጅምላ ሕትመት ዙር ውስጥ ይጨምሩ)። የካርድ ቁጥር በኮድ ደንብ ይመጣል።
3. ዙሩን ያትሙ › የጥራት ፍተሻ › "ታተመ"። ካርዱን ለሠራተኛው ሲሰጡ "ተሰጠ" ይጫኑ፤ ከዚያ ንቁ ነው።

**የጠፋ ካርድ መተካት**
1. የካርድ ጥያቄዎች › ጥያቄውን ይክፈቱ (ወይም ከካርዱ ገጽ "ጠፍቷል")። አሮጌው ካርድ ወዲያውኑ ይታገዳል፤ QR ው "የታገደ" ይላል።
2. አዲስ ካርድ ያውጡ፤ አሮጌው "የተተካ" ይሆናል። ታሪኩ ሁሉ በመዝገቡ ላይ ይቆያል።

**NFC ተርሚናል መመዝገብ**
1. የNFC ተርሚናሎች › አዲስ፡ ስም፣ ቦታ (ካፌቴሪያ/አውቶቡስ)፣ አቅራቢ። የተርሚናል ቁልፍ አንድ ጊዜ ይታያል፤ ይቅዱት።
2. ተርሚናሉ ካርድ ሲያነብ ማረጋገጫው በ "የNFC ማረጋገጫ መዝገቦች" ይታያል። ያልተሳካ ማረጋገጫ ብዙ ከሆነ ተርሚናሉን ይፈትሹ።

## ደንቦች

- አንድ ሠራተኛ አንድ ንቁ ካርድ ብቻ አለው።
- QR ኮዱ ከካርዱ ቁጥር ጋር የተሳሰረ ነው፤ ስም ቢቀየርም QR አይቀየርም። የሕዝብ ማረጋገጫ ገጹ ፎቶና ሙሉ ስም የሚያሳየው ካርዱ ንቁ ሲሆን ብቻ ነው።
- የታገደ፣ የተሰረዘ ወይም ያለፈበት ካርድ በካፌቴሪያ/ትራንስፖርት ተርሚናል አይሠራም።
- የካርድ ሁኔታ ለውጥ ሁሉ ከማን እንዳደረገው ጋር ይመዘገባል (ኦዲት)።

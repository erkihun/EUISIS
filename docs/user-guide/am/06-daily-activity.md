# 06 · ዕለታዊ የሥራ እንቅስቃሴ

**ለማን፡** ለኃላፊዎች (ገምጋሚዎች)፣ ለሰው ሀብት ክትትል ባለሙያዎች። ሠራተኛው ራሱ የሚመዘግበው ከ My Portal ነው ([01](01-my-portal.md))።

**ዓላማ፡** እያንዳንዱ ሠራተኛ በየቀኑ የሠራውን መመዝገብ፣ ኃላፊው ማረጋገጥ፣ የተመዘገበው ወደ አፈጻጸም (KPI ውጤት) መሄድ።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| የእንቅስቃሴ ዳሽቦርድ | የዛሬ/የሳምንቱ የመመዝገቢያ ሽፋን በክፍል፣ ያልቀረቡ፣ የሚጠብቁ ግምገማዎች። |
| የዕለታዊ እንቅስቃሴ መዝገብ | ሁሉም መዝገቦች፣ በሠራተኛ/በቀን/በሁኔታ ማጣራት። |
| ያልቀረቡ እንቅስቃሴዎች | በሥራ ቀን ያልመዘገቡ ሠራተኞች፤ ማስታወሻ መላክ። |
| የእንቅስቃሴ ግምገማ ወረፋ | ለእርስዎ የቀረቡ መዝገቦች፡ ማጽደቅ፣ ለማስተካከያ መመለስ፣ አስተያየት። |
| የእንቅስቃሴ ሪፖርቶች | በክፍል/በወር ማጠቃለያ፣ ወደ Excel/PDF። |
| የገምጋሚ ምደባዎች | ማን የማንን መዝገብ ይገመግማል (ነባሪው የቅርብ ኃላፊ ነው፤ እዚህ ይቀየራል)። |
| የእንቅስቃሴ ቅንብሮች | የመመዝገቢያ መስኮት (እስከ መቼ መመዝገብ ይቻላል)፣ የሥራ ሳምንት፣ የማስታወሻ ሰዓት። |

## ተደጋጋሚ ሥራዎች

**መዝገቦችን መገምገም**
1. የእንቅስቃሴ ግምገማ ወረፋ። እያንዳንዱን መዝገብ ይክፈቱ።
2. "አጽድቅ" ወይም "መልስ" ከአስተያየት ጋር። የተመለሰው ለሠራተኛው ማሳወቂያ ይሄዳል፤ አስተካክሎ እንደገና ያቀርባል።
3. በጅምላ ማጽደቅ፡ ብዙ ረድፎችን ይምረጡ › አጽድቅ።

**ያልመዘገበ ሠራተኛ ማስታወስ**
1. ያልቀረቡ እንቅስቃሴዎች › ቀን ይምረጡ › ሠራተኞቹን ይምረጡ › "ማስታወሻ ላክ"። ማሳወቂያና (ከተዋቀረ) SMS ይደርሳቸዋል።

**ገምጋሚ መቀየር**
1. የገምጋሚ ምደባዎች › ሠራተኛ ወይም ክፍል ይምረጡ › ገምጋሚ ይምረጡ › ከ–እስከ ቀን። ጊዜያዊ ውክልና ከሆነ የኃላፊ ውክልና ([04](04-employee-management.md)) ይመረጣል።

## ደንቦች

- የመመዝገቢያ መስኮቱ ካለፈ ሠራተኛው መመዝገብ አይችልም፤ ኃላፊው ቀኑን "ክፈት" ማለት ይችላል፣ ይመዘገባል።
- የጸደቀ መዝገብ አይስተካከልም፤ ገምጋሚው "ማጽደቁን ይቀልብስ" ካለ ብቻ።
- ያልጸደቀ መዝገብ ወደ አፈጻጸም ውጤት አይገባም።
- የመስክ ሥራ ቀን እንደ የሥራ ቀን ይቆጠራል፤ እንቅስቃሴው ከመስክ ሥራ ጥያቄው ጋር ይገናኛል።

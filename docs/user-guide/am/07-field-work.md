# 07 · የመስክ ሥራ አስተዳደር

**ለማን፡** ለኃላፊዎች (አጽዳቂዎች)፣ ለሰው ሀብት፣ ለክፍል አስተባባሪዎች። ሠራተኛው ጥያቄውን ከ My Portal ያቀርባል ([01](01-my-portal.md))።

**ዓላማ፡** ከቢሮ ውጭ የሚሠራ ሥራ በጥያቄ፣ በማጽደቅ፣ በቦታ ማረጋገጫ እና በመዝጋት እንዲመዘገብ፤ ማን የት እንደሆነ ለክፍሉ እንዲታወቅ።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| ዳሽቦርድ | የዛሬ በመስክ ያሉ፣ የሚጠብቁ ማጽደቆች፣ ያለፈባቸው። |
| የመስክ ሥራ ጥያቄዎች | ሁሉም ጥያቄዎች፣ ሁኔታ (ረቂቅ፣ የቀረበ፣ የጸደቀ፣ ውድቅ፣ በመካሄድ ላይ፣ የተዘጋ)። |
| ውሳኔ የሚጠብቁ | ለእርስዎ የቀረቡ ጥያቄዎች። |
| የቡድን የመስክ ሥራ | የክፍልዎ ሠራተኞች ጥያቄዎች በቀን መቁጠሪያ። |
| የቡድን ተገኝነት | ዛሬ ማን በቢሮ፣ ማን በመስክ እንደሆነ። |
| ጊዜው ያለፈ / ያልተዘጋ | የተጠናቀቀ ቀን ያለፈባቸው ነገር ግን ያልተዘጉ ጥያቄዎች። |
| የመስክ ሥራ ዓይነቶች | ዓይነቶች (ቁጥጥር፣ ስብሰባ፣ ዳሰሳ...) እና የእያንዳንዱ ደንብ (ማስረጃ ያስፈልጋል? የቦታ ማረጋገጫ ራዲየስ?)። |

## ተደጋጋሚ ሥራዎች

**ጥያቄ ማጽደቅ**
1. ውሳኔ የሚጠብቁ › ጥያቄውን ይክፈቱ፡ ዓላማ፣ ቦታ (ካርታ ላይ)፣ ቀናት፣ የቀደመ ታሪክ።
2. "አጽድቅ" ወይም "ውድቅ" ከምክንያት ጋር። ሠራተኛው ማሳወቂያ ይደርሰዋል።

**የመስክ ሥራ መዝጋት**
1. ሠራተኛው ሲመለስ ሪፖርትና ማስረጃ (ፎቶ፣ ሰነድ) ያቀርባል፤ ስልኩ የነበረበትን ቦታ ካረጋገጠ "ቦታ ተረጋግጧል" ይታያል።
2. ኃላፊው ያረጋግጣል › "ዝጋ"። ቀኑ በዕለታዊ እንቅስቃሴ ላይ "የመስክ ሥራ" ተብሎ ይመዘገባል።

**ዓይነት መጨመር**
1. የመስክ ሥራ ዓይነቶች › አዲስ፡ ስም (አማርኛ/English)፣ ማስረጃ ያስፈልጋል?፣ ከፍተኛ ቀናት፣ የቦታ ራዲየስ (ሜትር)።

## ደንቦች

- ያልጸደቀ የመስክ ሥራ ቀን እንደ ቅሬታ አይቆጠርም፤ እንደ ያልተመዘገበ ቀን ይቆጠራል።
- ከተፈቀደው ራዲየስ ውጭ የተደረገ የቦታ ማረጋገጫ "ያልተረጋገጠ" ተብሎ ይታያል፤ ኃላፊው ራሱ ሊቀበለው ይችላል፣ ምክንያቱ ይመዘገባል።
- ያለፈበት ያልተዘጋ ጥያቄ በዳሽቦርዱ ላይ ቀይ ይሆናል፤ በ 7 ቀናት ውስጥ ካልተዘጋ ለሰው ሀብት ይታያል።

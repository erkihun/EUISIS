# 08 · የሥራ አፈጻጸም አስተዳደር

**ለማን፡** ለዕቅድና አፈጻጸም ባለሙያዎች፣ ለኃላፊዎች፣ ለሰው ሀብት። ሠራተኛው የራሱን ስምምነትና ውጤት በ My Portal ያያል።

**ዓላማ፡** የከተማው ስትራቴጂ ወደ ተቋም ዕቅድ፣ ወደ ሠራተኛ ስምምነት፣ ወደ ዕለታዊ ሥራ ውጤት እንዲወርድ፤ ግምገማ፣ ማስተካከያ (calibration) እና ይግባኝ በአንድ ዑደት ውስጥ እንዲከናወን።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| የአፈጻጸም ዳሽቦርድ | የዑደቱ ደረጃ፣ ስምምነት የፈረሙ/ያልፈረሙ፣ የግምገማ ሽፋን። |
| የአፈጻጸም ዑደቶች | የዓመቱ/የግማሽ ዓመቱ ዑደት፡ መክፈቻ፣ የዕቅድ ጊዜ፣ የግምገማ ጊዜ፣ መዝጊያ። |
| ስትራቴጂ › ዋና ስትራቴጂዎች / የስትራቴጂክ ግብ ማስገቢያ / ስትራቴጂክ ግቦች | የስትራቴጂ ተዋረድ በ WLMS አሠራር፡ ዋና ስትራቴጂ › ግብ › ውጤት › ተግባር። |
| የአፈጻጸም ዕቅዶች | የተቋም/የክፍል ዕቅዶች ከስትራቴጂክ ግቦች ጋር የተገናኙ፤ የሚያጸድቀው ፈቃድ ያለው ብቻ። |
| የ KPI ቤተ-መጻሕፍት | የተለኪዎች ካታሎግ (ስም፣ መለኪያ፣ ምንጭ፡ ዕለታዊ ሥራ/የሕዝብ አስተያየት/በእጅ)። |
| የአፈጻጸም ስምምነቶች | የሠራተኛ ስምምነት፡ ዒላማዎች፣ ክብደት፣ ፊርማ (ሠራተኛና ኃላፊ)። |
| ማስተካከያ (Calibration) | በክፍሎች መካከል የውጤት ስርጭትን ማወዳደርና ማስተካከል። |
| ይግባኞች | ሠራተኛ በውጤቱ ላይ ያቀረበው ይግባኝ እና ውሳኔ። |
| ሪፖርቶች | በተቋም/በክፍል/በደረጃ ውጤት ስርጭት፣ ወደ Excel/PDF። |
| ቅንብሮች | የደረጃ ሚዛን (rating scale)፣ የግምገማ ዓይነቶች፣ ክብደቶች። |

## ተደጋጋሚ ሥራዎች

**አዲስ ዑደት መክፈት**
1. የአፈጻጸም ዑደቶች › አዲስ፡ ስም፣ ከ–እስከ፣ የዕቅድ ማብቂያ ቀን፣ የግምገማ መጀመሪያ ቀን።
2. ዑደቱ "ክፍት" ሲሆን ኃላፊዎች ስምምነቶችን ያዘጋጃሉ።

**የሠራተኛ ስምምነት ማዘጋጀት**
1. የአፈጻጸም ስምምነቶች › አዲስ › ሠራተኛ ይምረጡ። ዒላማዎች ከክፍሉ ዕቅድ ይመጣሉ፤ KPI ከቤተ-መጻሕፍቱ ይጨመራል፣ ክብደት ይሰጣል (ድምር 100%)።
2. "ለፊርማ ላክ" — ሠራተኛው በ My Portal ይፈርማል ወይም አስተያየት ይሰጣል።

**ግምገማ**
1. በግምገማ ጊዜ ኃላፊው እያንዳንዱን ዒላማ ይመዝናል። ከዕለታዊ ሥራ የሚመጡ KPI ዎች በራስ-ሰር ይሞላሉ (የጸደቁ መዝገቦች ብቻ)።
2. ውጤቱ ለሠራተኛው ይታያል፤ በተቀመጠው ቀናት ውስጥ ይግባኝ ማቅረብ ይችላል።

## ደንቦች

- የተፈረመ ስምምነት አይስተካከልም፤ "ማሻሻያ" ይወጣል፣ ሁለቱም እንደገና ይፈርማሉ።
- ሠራተኛ ወደ ሌላ መደብ ሲዛወር ስምምነቱ ይዘጋል፤ አዲስ ይወጣል።
- የተቋም ዕቅድ ማጽደቅ የተለየ ፈቃድ (performance_plans.approve) ይፈልጋል።

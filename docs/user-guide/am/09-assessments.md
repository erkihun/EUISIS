# 09 · ምዘናዎች

**ለማን፡** ለምዘና አስተባባሪዎች (ቅጽ አዘጋጆች)፣ ለገምጋሚዎች (ኃላፊዎች)፣ ለከተማ ደረጃ የክትትል ባለሙያዎች።

**ዓላማ፡** የብቃት/የአመለካከት ምዘናዎች በሥርዓቱ ውስጥ በተሠራ ቅጽ እንዲሞሉ፣ እንዲገመገሙ፣ ውጤታቸው እንዲመዘገብና በከተማ ደረጃ ሽፋንና ጥራት እንዲታይ።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| የምዘና ቅጾች | ቅጽ መሥራት (ክፍሎች፣ ጥያቄዎች፣ የውጤት ሚዛን)፣ ስሪት ማውጣት፣ ለተቋማት መመደብ። |
| ለእኔ የተመደቡ ምዘናዎች | እርስዎ እንደ ገምጋሚ የሚሞሏቸው። |
| ግምገማ የሚጠብቁ ምዘናዎች | የተሞሉና ማጽደቅ የሚጠብቁ። |
| የምዘና መዝገቦች | የተጠናቀቁ ምዘናዎች በሠራተኛ፣ ከውጤትና ከስሪት ጋር። |
| የክትትል ዳሽቦርድ / ተቋማት / ሽፋን / ስርጭት / ጾታ / የመረጃ ጥራት / የቀረቡ / ሪፖርቶች / ማዋቀሪያ | የከተማ ደረጃ እይታ፡ የትኛው ተቋም ምን ያህል እንደሸፈነ፣ የውጤት ስርጭት፣ በጾታ፣ የጎደሉ መረጃዎች፣ የቀረቡ ማጠቃለያዎች። |

## ተደጋጋሚ ሥራዎች

**ቅጽ ማዘጋጀት**
1. የምዘና ቅጾች › አዲስ፡ ስም፣ ዓላማ፣ የሚመለከታቸው የሥራ መደቦች/ሙያዎች።
2. ክፍሎችና ጥያቄዎች ይጨምሩ (ምርጫ፣ ደረጃ፣ ጽሑፍ)፤ ለእያንዳንዱ ክብደት።
3. የውጤት ሚዛን ይምረጡ (ከአፈጻጸም ቅንብር የሚመጣ)።
4. "ስሪት አውጣ" — ከዚያ በኋላ ጥያቄዎቹ አይቀየሩም፤ ለውጥ ካስፈለገ አዲስ ስሪት።
5. ለተቋማት/ለሠራተኞች ይመድቡ፤ የቀነ ገደብ ይስጡ።

**ምዘና መሙላት (ገምጋሚ)**
1. ለእኔ የተመደቡ ምዘናዎች › ይክፈቱ። ረቂቅ ይቀመጣል፤ ሁሉንም ሲሞሉ "አስገባ"።
2. የተመደበው ገምጋሚ የቅርብ ኃላፊ ነው (ከዕለታዊ ሥራ የገምጋሚ ምደባ)፤ ተጠባባቂ ካለ ወደ እሱ ይሄዳል።

**ውጤት ማረም**
1. የምዘና መዝገቦች › መዝገቡን ይክፈቱ › "እርማት"። ምክንያት ይጻፉ፤ የቀድሞው ውጤት በታሪክ ይቀመጣል።

**ይግባኝ**
- ሠራተኛው በ My Portal › የእኔ ምዘናዎች ይግባኝ ያቀርባል፤ አስተባባሪው ይመለከታል፣ ያጸድቃል ወይም ይመልሳል።

## ደንቦች

- የታተመ ስሪት አይቀየርም፤ የተሞሉ ምዘናዎች ሁልጊዜ የተሞሉበትን ስሪት ያመለክታሉ።
- ለሁለተኛ ጊዜ የቀረበ ምዘና (duplicate) በመረጃ ጥራት ገጽ ይታያል።
- የክትትል ገጾች የተቋም ወሰን ያላቸው ተጠቃሚዎች የራሳቸውን ተቋም ብቻ ያያሉ።

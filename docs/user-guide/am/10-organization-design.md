# 10 · የተቋም አደረጃጀትና የሰው ኃይል ዕቅድ

**ለማን፡** ለአደረጃጀትና የሥራ ጥናት ባለሙያዎች (ከተማ እና ተቋም ደረጃ)፣ ለሰው ኃይል ዕቅድ ባለሙያዎች።

**ዓላማ፡** ከሕጋዊ ሥልጣን እስከ የሥራ መደብ ድረስ ያለው ሰንሰለት (ሥልጣን › ተግባር › አገልግሎት › ሂደት › ሙያ › መደብ) በመረጃ እንዲቀመጥ፤ የአደረጃጀት ጥናትና የሰው ኃይል ዕቅድ በዚያ ላይ እንዲሠራ።

## ገጾች (ከሕግ እስከ መደብ)

| ስብስብ | ገጾች | ምን ያደርጋሉ |
|---|---|---|
| የቀድሞ መዝገቦችና የሕግ ምንጮች | አጠቃላይ እይታ፣ የቀድሞ መነሻ መዝገቦች፣ የሕግ ምንጮች፣ የንድፍ ማስመጫዎች | የነበረው መዋቅር እንደ መነሻ ይቀመጣል (wizard)፤ አዋጆች/ደንቦች ከሰነዶቻቸው ጋር ይመዘገባሉ፤ ካታሎጎች ከ Excel/CSV ይገባሉ። |
| ከሥልጣን እስከ ሂደት | ሕጋዊ ሥልጣንና ተግባራት፣ ተግባራት፣ የአገልግሎት ካታሎግ፣ ምደባዎች፣ የሥራ ሂደቶችና ስታንዳርዶች | የአዋጅ 94/2019 ሥልጣኖች ተመዝግበዋል፤ እያንዳንዱ ተግባር ከሥልጣን፣ እያንዳንዱ አገልግሎት ከተግባር፣ እያንዳንዱ ሂደት ከአገልግሎት ይገናኛል። |
| የሙያ ምድቦችና ብቃቶች | የሙያ ምድቦችና ሙያዎች፣ የብቃት ካታሎግ | ISCO-08 ሙያዎች፣ የብቃት መግለጫዎች፣ የሥራ መስፈርቶች። |
| መዋቅር | የአደረጃጀት ጥናቶች፣ የኃላፊነት ማትሪክስ፣ የመዋቅር ማረጋገጫ | ጥናት መክፈት፣ የክፍል ሀሳብ፣ ማን ለምን ኃላፊ ነው፣ የመዋቅር በር (gate) ፍተሻ፣ የተጽዕኖ እይታ። |
| የሰው ኃይልና የሥራ መደቦች | የዕቅድ ዘዴዎች፣ የሰው ኃይል ዕቅዶች፣ የሥራ መደብ ንድፍና የሥራ መግለጫዎች | በሥራ ጫና/በመስፈርት የሚቆጠር ፍላጎት፣ የመደብ መገለጫዎች፣ የሥራ መግለጫ PDF። |
| ሪፖርቶችና የመረጃ ጥራት | የአደረጃጀት ሪፖርቶች፣ የመረጃ ማዛመጃ | ክትትል (ከሥልጣን እስከ መደብ)፣ የክፍተት ሪፖርት፣ የቀድሞ ኮዶች ማዛመድ፣ የጥራት ጉዳዮች። |

## ተደጋጋሚ ሥራዎች

**የአደረጃጀት ጥናት ማካሄድ**
1. የአደረጃጀት ጥናቶች › አዲስ፡ ተቋም፣ ዓላማ፣ የሕግ ምንጭ።
2. የክፍል ሀሳቦችን ይጨምሩ (አዲስ/መቀላቀል/መዝጋት)፣ ለእያንዳንዱ የተግባር ምደባ።
3. የመዋቅር ማረጋገጫ ይክፈቱ፡ በሮች (ተግባር የሌለው ክፍል፣ ኃላፊ የሌለው ክፍል፣ የተደጋገመ አገልግሎት) ይፈተሻሉ።
4. ሲጸድቅ ወደ የተቋም መዋቅር የለውጥ ጥያቄ ይሆናል ([02](02-organization-structure.md))።

**የሰው ኃይል ዕቅድ**
1. የዕቅድ ዘዴዎች › ዘዴ ይምረጡ (የሥራ ጫና፣ ጥምርታ፣ ስታንዳርድ)።
2. የሰው ኃይል ዕቅዶች › አዲስ › ክፍሎችን ይምረጡ › ግብዓት (የሥራ መጠን፣ ስታንዳርድ ሰዓት)። ፍላጎቱ ይሰላል፤ ከነባሩ መደብ ጋር ይነጻጸራል።
3. ሪፖርቱን ለውሳኔ ያውጡ።

**የሥራ መግለጫ**
1. የሥራ መደብ ንድፍ › መደብ ይምረጡ › ተግባራት፣ መስፈርቶች፣ ብቃቶች ከካታሎጉ ያገናኙ › "PDF"።

## ደንቦች

- ከሕግ ምንጭ ያልተገናኘ ሥልጣን "ያልተደገፈ" ተብሎ በክፍተት ሪፖርት ይታያል።
- የጸደቀ ጥናት አይቀየርም፤ አዲስ ጥናት ይከፈታል።
- ለተቋም የሚታየው የራሱ ሰንሰለት ብቻ ነው፤ የከተማ ደረጃ ባለሙያ ሁሉንም ያያል።

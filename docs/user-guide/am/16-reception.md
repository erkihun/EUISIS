# 16 · መቀበያ እና መረጃ ጠረጴዛ

**ለማን፡** ለመቀበያ ባለሙያዎች (ጎብኚ መቀበያ)፣ ለአገልግሎት መስኮት ኃላፊዎች፣ ለተቋም አስተዳደር።

**ዓላማ፡** ወደ ተቋም የሚመጣ እያንዳንዱ ተገልጋይ እንዲመዘገብ፣ ወደ ትክክለኛው መስኮት እንዲመራ፣ በወረፋ እንዲስተናገድ፤ የጥበቃ ጊዜ እንዲለካ።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| የመቀበያ ዳሽቦርድ | የዛሬ ጎብኚዎች፣ በመጠበቅ ላይ፣ አማካይ የጥበቃ ጊዜ በመስኮት። |
| ጎብኚ ይመዝግቡ | ስም፣ ስልክ (አማራጭ)፣ የመጣበት አገልግሎት፣ የሚፈልገው ክፍል/ሠራተኛ › የወረፋ ቁጥር። |
| የዛሬ ጎብኚዎች | የዛሬ ዝርዝር፣ ሁኔታ (በመጠበቅ፣ በአገልግሎት ላይ፣ ተጠናቅቋል፣ ተመልሷል)። |
| የወረፋ አስተዳደር | በመስኮት/በጠረጴዛ ወረፋ፣ "ቀጣይ ጥራ"፣ ማስተላለፍ። |
| ቀጠሮዎች | አስቀድሞ የተያዘ ቀጠሮ፤ ሲመጣ "ደርሷል"። |
| የአገልግሎት ማውጫ | የተቋሙ አገልግሎቶች፣ የሚሰጥበት መስኮት፣ የሚያስፈልጉ ሰነዶች (ለጎብኚው ማሳወቂያ)። |
| ሪፈራሎች | ወደ ሌላ ተቋም/ክፍል የተላከ ተገልጋይ፣ ከማመልከቻ ቁጥር ጋር። |
| ጠረጴዛዎች እና መስኮቶች | የመቀበያ ጠረጴዛዎችና የአገልግሎት መስኮቶች፣ ማን እንደሚሠራባቸው። |
| የመቀበያ ሪፖርቶች | በቀን/በሳምንት ብዛት፣ የጥበቃ ጊዜ፣ በአገልግሎት። |

## ተደጋጋሚ ሥራዎች

**ጎብኚ መመዝገብ**
1. ጎብኚ ይመዝግቡ › አገልግሎት ይምረጡ (ማውጫው የሚያስፈልጉ ሰነዶችን ያሳያል፤ ለጎብኚው ይንገሩ)።
2. "መዝግብ" › የወረፋ ቁጥር ይታተማል/ይነገራል። ስልክ ከተሰጠ SMS ይላካል (ከተዋቀረ)።

**ወረፋ ማስኬድ (መስኮት)**
1. የወረፋ አስተዳደር › የእርስዎ መስኮት › "ቀጣይ ጥራ"። ሲጨርሱ "ተጠናቀቀ" ወይም "አስተላልፍ" ወደ ሌላ መስኮት።

**ቀጠሮ**
1. ቀጠሮዎች › አዲስ፡ ተገልጋይ፣ አገልግሎት፣ ቀንና ሰዓት። በቀኑ ሲመጣ "ደርሷል" — ወደ ወረፋ ግንባር ይገባል።

## ደንቦች

- የጎብኚ ስልክ ቁጥር ለ SMS ማሳወቂያ ብቻ ይውላል፤ በመረጃ ጥበቃ ደንቡ መሠረት ከተወሰነ ጊዜ በኋላ ይሰረዛል (ADR 0027)።
- የመቀበያ ሪፖርት የሚያሳየው ድምርና ጊዜ ነው እንጂ የግለሰብ ስም ዝርዝር አይደለም።
- ሪፈራል ሲሰጥ የተቀባዩ ተቋም መቀበያ ያያል (ሁለቱም በሥርዓቱ ካሉ)።

# 18 · ካፌቴሪያ

**ለማን፡** ለካፌቴሪያ አስተዳደር ባለሙያዎች (ተቋም/ከተማ)፣ ለአቅራቢዎች (በራሳቸው ፖርታል)፣ ለመቃኛ ጣቢያ ሠራተኞች፣ ለገንዘብ ማወራረጃ ባለሙያዎች።

**ዓላማ፡** የሠራተኛ ምሳ ድጎማ በካርድ መቃኘት እንዲመዘገብ፣ ሁለቴ እንዳይቆጠር፣ ለአቅራቢው በወር እንዲወራረድ፣ ለተቋሙ ወጪው እንዲታይ።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| የካፌቴሪያ ዳሽቦርድ | የዛሬ ግብይቶች፣ በካፌቴሪያ፣ ያልተለመዱ ሁኔታዎች (ተደጋጋሚ መቃኘት)። |
| የካርድ መቃኛ ጣቢያ | የካርድ QR/NFC መቃኛ ገጽ፡ ካርዱን ያነባል፣ ብቁነትን ያረጋግጣል፣ ግብይቱን ይመዘግባል። |
| አቅራቢዎች / የካፌቴሪያ ኔትወርኮች / ካፌቴሪያዎች | አቅራቢ ድርጅቶች፣ የካፌቴሪያ ቦታዎችና ኔትወርኮቻቸው። |
| የተቋም ፈቃድ / የአገልግሎት ምደባዎች | የትኛው ተቋም ሠራተኞች በየትኛው ካፌቴሪያ ይመገባሉ። |
| ሠራተኛ ፈቃድ / ማግለሎች | ለግለሰብ ሠራተኛ መፍቀድ/ማገድ ከምክንያት ጋር። |
| የአገልግሎት ፖሊሲዎች / የሥራ ቀናት / ልዩ ቀናት / ሕዝባዊ በዓላት | በቀን ስንት ጊዜ፣ በምን ሰዓት፣ የትኞቹ ቀናት፤ በዓላት ከኢትዮጵያ የበዓል ዝርዝር። |
| ግብይቶች | ሁሉም መቃኘቶች፣ ማጣሪያ፣ ወደ Excel። |
| የድጎማ ሂሳብ | በተቋም/በአቅራቢ የተጠራቀመ ድጎማ (ledger)። |
| የሂሳብ ማወራረጃዎች | የወር ማወራረጃ ማዘጋጀት፣ ማረጋገጥ፣ በሁለተኛ ሰው ማጽደቅ (ውሳኔ D-6)። |
| ሪፖርቶች / የትንተና ሪፖርቶች | በቀን/በወር/በተቋም/በአቅራቢ፤ አዝማሚያ። |
| የሥርዓት ነባሪዎች | ለሁሉም ተቋማት የሚሠሩ ነባሪ ቅንብሮች። |

## ተደጋጋሚ ሥራዎች

**መቃኘት (ጣቢያ)**
1. የካርድ መቃኛ ጣቢያ › ካፌቴሪያውን ይምረጡ (አንዴ)። ካርዱን ያሳዩ (QR ካሜራ ወይም NFC)።
2. አረንጓዴ፡ ተመዝግቧል። ቀይ፡ ምክንያቱ ይታያል (ዛሬ ተመግቧል፣ ካርድ ታግዷል፣ ተቋሙ አልተፈቀደም፣ ከሰዓት ውጭ)። ተርሚናሉ ሳይገናኝ ሲቀር መቃኘቶቹ ተቀምጠው ሲገናኝ ይላካሉ።

**የወር ማወራረጃ**
1. የሂሳብ ማወራረጃዎች › አዲስ › አቅራቢ፣ ወር › "አዘጋጅ"። ግብይቶቹ ይጠቃለላሉ፣ ልዩነቶች ይታያሉ።
2. አዘጋጁ "አረጋግጥ"፤ **ሌላ ሰው** "አጽድቅ"። ከዚያ አይቀየርም፤ የማወራረጃ መግለጫ PDF ይወጣል።

**ሠራተኛ ማገድ**
1. ሠራተኛ ፈቃድ / ማግለሎች › አዲስ ማግለል፡ ሠራተኛ፣ ከ–እስከ፣ ምክንያት። ወዲያውኑ ተርሚናሉ ይከለክላል።

## ደንቦች

- በአንድ ቀን ከፖሊሲው ብዛት በላይ መቃኘት "ተደጋጋሚ" ተብሎ ይታገዳል እና ይመዘገባል።
- አቅራቢው በራሱ ፖርታል የራሱን ግብይቶችና ማወራረጃ ብቻ ያያል፤ የሠራተኛ ስም ዝርዝር አያይም።
- ማወራረጃ ከጸደቀ በኋላ የተገኘ ስህተት በሚቀጥለው ወር እንደ ማስተካከያ ይገባል።

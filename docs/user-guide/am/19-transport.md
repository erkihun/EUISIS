# 19 · ትራንስፖርት

**ለማን፡** ለሠራተኛ ትራንስፖርት አስተዳደር ባለሙያዎች፣ ለትራንስፖርት አቅራቢዎች (የራሳቸው ፖርታል)፣ ለአሽከርካሪዎች/ለመቃኛ መሣሪያ ኦፕሬተሮች፣ ለገንዘብ ማወራረጃ።

**ዓላማ፡** የሠራተኛ አገልግሎት አውቶቡስ አጠቃቀም በካርድ መቃኘት እንዲረጋገጥ፣ ጉዞዎች እንዲታቀዱ፣ ለአቅራቢው በጉዞ መሠረት እንዲከፈል።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| የትራንስፖርት አጠቃላይ እይታ | የዛሬ ጉዞዎች፣ የተሳፈሩ፣ ልዩ ሁኔታዎች። |
| መታወቂያ ካርድ ይቃኙ | የመሳፈሪያ መቃኛ ገጽ (ለመሣሪያ ወይም ለስልክ)። |
| ጉዞዎች እና ማሰማራት | የዛሬ/የሳምንቱ ጉዞዎች፡ መስመር፣ ተሽከርካሪ፣ አሽከርካሪ፣ ሰዓት፣ ሁኔታ። |
| የመሳፈሪያ መዝገቦች | እያንዳንዱ መቃኘት (ማን፣ መቼ፣ የት ጉዞ)። |
| የትራንስፖርት ልዩ ሁኔታዎች | ያልተሳኩ መቃኘቶች፣ ያልታቀደ ጉዞ ላይ መሳፈር፣ ተደጋጋሚ። |
| አቅራቢዎች / መስመሮች / የጉዞ መርሃ ግብሮች / ተሽከርካሪዎች / አሽከርካሪዎች / የመቃኛ መሣሪያዎች | የመሠረታዊ መረጃ ገጾች። |
| ፓሶች / የትራንስፖርት ብቁነት | ለሠራተኛ የተሰጠ ፓስ (መስመር፣ ጊዜ)፤ ብቁነት ደንቦች። |
| የትራንስፖርት ውሎች / የአቅራቢ ደረሰኞች / የክፍያ ማቻቻሎች | ውል (ዋጋ በጉዞ/በወር)፣ የአቅራቢ ደረሰኝ፣ ማወራረጃ ከመሳፈሪያ መዝገቦች ጋር ተነጻጽሮ። |
| ሪፖርቶች / የትራንስፖርት ቅንብሮች | አጠቃቀም፣ ወጪ፣ ሽፋን፤ ቅንብሮች። |

## ተደጋጋሚ ሥራዎች

**መስመርና መርሃ ግብር ማዘጋጀት**
1. መስመሮች › አዲስ፡ ስም፣ ማቆሚያዎች፣ አቅራቢ።
2. የጉዞ መርሃ ግብሮች › አዲስ፡ መስመር፣ ቀናት፣ ሰዓታት፣ ተሽከርካሪ፣ አሽከርካሪ። ጉዞዎች በራስ-ሰር ይፈጠራሉ።

**መሳፈር (መሣሪያ)**
1. መታወቂያ ካርድ ይቃኙ › ጉዞውን ይምረጡ › ካርዶችን ይቃኙ። አንድ የመሳፈሪያ ሞተር ብቻ ነው፤ ማንኛውም መቃኘት በዚያ ያልፋል (ፓስ፣ ብቁነት፣ የካርድ ሁኔታ)።

**የአቅራቢ ክፍያ ማቻቻል**
1. የክፍያ ማቻቻሎች › አዲስ › አቅራቢ፣ ወር። የአቅራቢው ደረሰኝ ከመሳፈሪያ መዝገቦች ጋር ይነጻጸራል፤ ልዩነቶች ይታያሉ።
2. "አረጋግጥ" › ሁለተኛ ሰው "አጽድቅ"።

## ደንቦች

- ፓስ የሌለው ወይም ብቁ ያልሆነ ሠራተኛ መቃኘቱ "ልዩ ሁኔታ" ተብሎ ይመዘገባል፤ ኦፕሬተሩ እንዲሳፈር ሊፈቅድ ይችላል፣ ይመዘገባል።
- ያልታቀደ ጉዞ ላይ የተደረገ መቃኘት ለክፍያ አይቆጠርም እስኪገመገም።
- አቅራቢው የራሱን ጉዞዎች፣ መዝገቦችና ማወራረጃ ብቻ ያያል።
- ትራንስፖርት ሞጁሉ በምርት በአስተዳዳሪ ካልተከፈተ ምናሌው አይታይም (feature gate)።

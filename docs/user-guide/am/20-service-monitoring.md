# 20 · የአገልግሎት ክትትል

**ለማን፡** ለተቋም የአገልግሎት ሪፖርት አዘጋጆች፣ ለክፍለ ከተማ ገምጋሚዎች፣ ለከተማ ደረጃ ማጠቃለያና ማረጋገጫ ባለሙያዎች፣ ለክትትል ጉብኝት ቡድኖች።

**ዓላማ፡** የተቋማት የአገልግሎት አሰጣጥ ሪፖርት በተወሰነ ጊዜ (ሩብ ዓመት/ወር) በአንድ ቅጽ እንዲቀርብ፣ በክፍለ ከተማ እንዲገመገም፣ በከተማ እንዲጠቃለል፣ በጉብኝት እንዲረጋገጥ፣ የእርምጃ ተግባሮች እንዲከታተሉ።

## ገጾች

| ገጽ | ምን ያደርጋል |
|---|---|
| ዳሽቦርድ | የጊዜው ሁኔታ፡ ያቀረቡ/ያላቀረቡ ተቋማት፣ በግምገማ፣ የቀነ ገደብ። |
| ሪፖርቶች (የቀረቡ) | የእርስዎ ተቋም ሪፖርቶች፡ ረቂቅ፣ የቀረበ፣ የተመለሰ፣ የጸደቀ። |
| የግምገማ ወረፋ | ለገምጋሚው የቀረቡ ሪፖርቶች፤ ማጽደቅ፣ ማብራሪያ መጠየቅ፣ መመለስ። |
| የበላይ ተቋም (ክፍለ ከተማ) / አጠቃላይ ማጠቃለያ (ከተማ) | የተጠቃለሉ ውጤቶች በደረጃ። |
| የማረጋገጫ ወረፋ | ናሙና ሪፖርቶችን በማስረጃ ማረጋገጥ። |
| ጊዜያትና የጊዜ ገደቦች | የሪፖርት ጊዜ መክፈት/መዝጋት፣ ቀነ ገደቦች፣ መቆለፍ። |
| ተቋማት (ተሳታፊዎች) | በዚህ ጊዜ ሪፖርት የሚያቀርቡ ተቋማት። |
| ክፍት የማብራሪያ ጥያቄዎች | ገምጋሚ የጠየቀውና ተቋሙ ያልመለሰው። |
| የክትትል ጉብኝቶች | የመስክ ጉብኝት ዕቅድ፣ ግኝቶች፣ ፎቶ። |
| የድርጊት ተግባሮች | ከግምገማ/ከጉብኝት የወጡ እርምጃዎች፣ ባለቤት፣ ቀነ ገደብ፣ ሁኔታ። |
| ሪፖርቶች / የቅጽ አብነቶች / ቅንብሮች | ማጠቃለያዎች፤ ቅጹ በ UI ይሠራል (ክፍሎች፣ አመልካቾች፣ የማስረጃ መስፈርት)። |

## ተደጋጋሚ ሥራዎች

**ሪፖርት ማቅረብ (ተቋም)**
1. ሪፖርቶች › የክፍት ጊዜው ሪፖርት › ይሙሉ (ክፍል በክፍል፣ ረቂቅ ይቀመጣል)፣ ማስረጃ ያያይዙ።
2. "አስገባ" ከቀነ ገደቡ በፊት። ከዚያ በኋላ ይቆለፋል፤ ገምጋሚው ከመለሰው ብቻ ይከፈታል።

**መገምገም (ክፍለ ከተማ)**
1. የግምገማ ወረፋ › ሪፖርቱን ይክፈቱ። ጥያቄ ካለ "ማብራሪያ ጠይቅ" — ተቋሙ በክፍት ጥያቄዎች ይመልሳል።
2. "አጽድቅ" ወይም "መልስ"። የጸደቀው ወደ ማጠቃለያ ይገባል።

**ጉብኝትና እርምጃ**
1. የክትትል ጉብኝቶች › አዲስ › ተቋም፣ ቀን፣ ቡድን። በቦታው ግኝቶችን ይመዝግቡ።
2. ከግኝት "የድርጊት ተግባር ፍጠር" › ባለቤትና ቀነ ገደብ። ተቋሙ ሲጨርስ "ተጠናቀቀ" ይላል፣ ገምጋሚው ያረጋግጣል።

## ደንቦች

- የተቆለፈ ጊዜ ሪፖርት አይቀበልም፤ ዘግይቶ ማቅረብ የከተማ ደረጃ ፈቃድ ይፈልጋል፣ ይመዘገባል።
- የቅጽ አብነት ሲቀየር አዲስ ስሪት ይወጣል፤ የቀረቡ ሪፖርቶች የቀድሞውን ስሪት ይዘው ይቆያሉ።
- ተቋም የራሱን ሪፖርት ብቻ ያያል፤ ክፍለ ከተማ የሥሩን፤ ከተማ ሁሉንም።

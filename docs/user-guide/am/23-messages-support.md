# 23 · መልዕክቶችና የድጋፍ ጥያቄዎች

**ለማን፡** ለሁሉም ተጠቃሚዎች። የድጋፍ ጥያቄዎችን የሚመልሰው የሥርዓት አስተዳዳሪ/የእገዛ ዴስክ ነው።

## መልዕክቶች (ከላይኛው አሞሌ የደብዳቤ ምልክት)

የውስጥ መልዕክት መለዋወጫ፡ የግል ውይይት፣ የቡድን ቻናል (የሥራ ክፍል፣ ኮሚቴ)፣ ማስታወቂያ ቻናል።

| ነገር | ምን ያደርጋል |
|---|---|
| ቻናሎች | የሥራ ክፍልዎ ቻናል በራስ-ሰር ይፈጠራል፤ ሲዛወሩ ይቀየራል። ኮሚቴ ቻናል ኮሚቴው ሲቋቋም ይከፈታል። |
| የግል መልዕክት | ማንኛውንም ሠራተኛ በስም ፈልገው ይጻፉ። |
| ማያያዣ | ሰነድ/ፎቶ፤ ከመቀመጡ በፊት ይፈተሻል (ቫይረስ)። |
| ፍለጋ | በቻናሎች ውስጥ ጽሑፍ ፍለጋ። |
| ያልተነበበ | በላይኛው አሞሌ ቁጥር፤ በቅጽበት ይዘምናል። |
| የትኩረት ሁነታ | መልዕክቶቹን ሙሉ ማያ ገጽ ማድረግ። |

**ደንቦች፡** መልዕክቶች የተቋሙ መዝገብ ናቸው፤ መሰረዝ "ተሰርዟል" ምልክት ያስቀምጣል እንጂ ታሪኩን አያጠፋም። ለአስተዳዳሪም ቢሆን የግል ውይይት ያለ ፈቃድና ያለ ምክንያት አይከፈትም (የ Super Admin ልዩ ሁኔታ ይመዘገባል)።

## የድጋፍ ጥያቄዎች (የራስ አገልግሎት › የድጋፍ ጥያቄዎች)

ስለ ሥርዓቱ ችግር ወይም ጥያቄ፡ መግባት አልቻልኩም፣ ገጽ አይከፈትም፣ መረጃ ተሳስቷል፣ ፈቃድ የለኝም።

**ጥያቄ መክፈት**
1. የድጋፍ ጥያቄዎች › አዲስ፡ ርዕስ፣ ምድብ (መግቢያ/ፈቃድ/መረጃ/ስህተት/ሌላ)፣ መግለጫ፣ ስክሪንሾት።
2. የጥያቄ ቁጥር ይሰጣል። መልስ ሲመጣ ማሳወቂያ ይደርስዎታል፤ በጥያቄው ውስጥ ይመልሱ።
3. ሲፈታ "ተዘግቷል"፤ ካልረኩ እንደገና ይክፈቱ።

**ለእገዛ ዴስክ**
- ወረፋው በ "የድጋፍ ጥያቄዎች" (የአስተዳዳሪ እይታ) ነው፤ መመደብ፣ ምድብ መቀየር፣ ወደ ክስተት (Intelligence) ማሳደግ።
- ተደጋጋሚ ጥያቄዎች የዕውቀት ረዳቱ ሰነድ መሆን አለባቸው — መልሱን ወደ docs/user-guide ያስገቡ።

**ከረዳቱ ጋር፡** ረዳቱ ([22](22-intelligence.md)) መልስ ካላገኘ "የድጋፍ ጥያቄ ክፈት" ይላል፤ ውይይቱ ከጥያቄው ጋር ይያያዛል።

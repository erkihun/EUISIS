# 25 · አስተዳደርና ሥርዓት

**ለማን፡** ለሥርዓት አስተዳዳሪዎች (Super Admin / System Admin)፣ ለከተማ አስተዳዳሪ (City Admin)፣ ለተቋም አስተዳዳሪዎች (በተቋም ወሰን)።

**ዓላማ፡** ማን ምን እንደሚያይና እንደሚያደርግ፣ ሥርዓቱ እንዴት እንደተዋቀረ፣ ምን እንደተደረገ (ኦዲት)፣ እና መረጃው እንደተጠበቀ (ባካፕ) በአንድ ቦታ።

## የመዳረሻ ቁጥጥር

| ገጽ | ምን ያደርጋል |
|---|---|
| ተጠቃሚዎች | መለያዎች፡ መፍጠር፣ ከሠራተኛ መዝገብ ጋር ማገናኘት፣ ሚና መስጠት፣ የተቋም ወሰን፣ ማቦዘን፣ MFA ዳግም ማስጀመር። |
| ሚናዎች | 105 ነባሪ ሚናዎች (በአማርኛ ስም) እና የተቋም ልዩ ሚናዎች፤ የእያንዳንዱ ፈቃዶች። |
| የመዳረሻ መብቶች | የፈቃድ ካታሎግ (ለንባብ)። |
| የኦዲት መዝገቦች | ማን መቼ ምን እንዳደረገ፤ የታሸጉ (sealed) መዝገቦች አይቀየሩም። |

**ተጠቃሚ መፍጠር**
1. ተጠቃሚዎች › አዲስ፡ ስም፣ ኢሜይል/ስልክ፣ የሠራተኛ መዝገብ (ከተገኘ)፣ ሚና(ዎች)፣ የተቋም ወሰን።
2. ጊዜያዊ የይለፍ ቃል ይላካል፤ በመጀመሪያ መግቢያ ይቀየራል። ልዩ መብት ያለው ሚና ከሆነ MFA ግዴታ ነው።

**ሚና መምረጥ ደንብ**
- ለዕለት ሥራ **City Admin አይስጡ**። ለእያንዳንዱ ዘርፍ የሚሠራ ሚና አለ (ለምሳሌ "የቅሬታ ባለሙያ"፣ "የመታወቂያ ኦፕሬተር")። ሚና በሌለበት ክፍተት ካለ የድጋፍ ጥያቄ ይክፈቱ፤ ADR 0026 ይመልከቱ።
- የተቋም ደረጃ ሚና ያለው ተጠቃሚ **የተቋም ወሰን መዝገብ** ያስፈልገዋል፤ ያለ ወሰን ምንም አያይም (fail-closed)። `access:scope-gaps` ትዕዛዝ ክፍተቶችን ይዘረዝራል።
- የመጨረሻው Super Admin አይቦዝንም፣ ሚናው አይነሳም።

## የሳምንት የአስተዳዳሪ ፍተሻ

1. ባካፕ እና መልሶ ማግኛ — አረንጓዴ? የልምምድ ቀን?
2. የኦዲት መዝገቦች — ያልተለመደ የመግቢያ ሙከራ፣ የ break-glass መዳረሻ።
3. ተጠቃሚዎች — ከሥራ የወጡ ሠራተኞች መለያ ቦዝኗል? (ምደባ ሲዘጋ በራስ-ሰር ይቦዝናል፤ ያረጋግጡ።)
4. አስተውሎት › የሥርዓት ጤንነት — ወረፋ፣ የተበላሹ ሥራዎች ([22](22-intelligence.md))።
5. የድጋፍ ጥያቄዎች — ያልተመለሰ የለም?

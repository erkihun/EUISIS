# አገልጋይ · የተጠቃሚ መመሪያ

ይህ መመሪያ ለሥርዓቱ ተጠቃሚዎች ነው፡ ለሠራተኞች፣ ለሰው ሀብት ባለሙያዎች፣ ለኃላፊዎች፣ ለአገልግሎት ሰጪ ጠረጴዛዎች እና ለአስተዳዳሪዎች። ለገንቢዎችና ለሥርዓት ኦፕሬተሮች የተጻፉት ሰነዶች በ `docs/` ሥር በእንግሊዝኛ ይገኛሉ።

እያንዳንዱ ገጽ አንድ የምናሌ ክፍል ይሸፍናል፤ ርዕሶቹ በሥርዓቱ ምናሌ ላይ ከሚታዩት ስሞች ጋር አንድ ናቸው።

**ረቂቅ፡** እነዚህ ገጾች የተጻፉት ከምናሌው ስሞችና ከሰነዶች ነው፤ በሥርዓቱ ገጾች ላይ አንድ በአንድ አልተረጋገጡም። ደረጃዎቹ፣ ቁጥሮቹና ደንቦቹ ለሥልጠና ከመዋላቸው በፊት በሥርዓቱ ላይ መፈተሽ አለባቸው።

## አጠቃቀም ማስታወሻ

- ምናሌው የሚያሳየው ተጠቃሚው **ፈቃድ ያለውን** ገጽ ብቻ ነው። አንድ ገጽ ካልታየ ሚና ወይም የተቋም ወሰን ጉዳይ ነው፤ ወደ አስተዳዳሪው ይጠይቁ ([25](25-administration.md))።
- ቋንቋ (አማርኛ/English) እና ቀን (የኢትዮጵያ/የግሪጎሪያን) ከላይኛው አሞሌ ይቀየራሉ፤ ምርጫው ለእያንዳንዱ ተጠቃሚ ይታወሳል።
- በእያንዳንዱ ዝርዝር ገጽ ላይ ያለው የማጣሪያ አሞሌ አንድ ዓይነት ነው፡ ፍለጋ፣ ማጣሪያዎች፣ ወደ Excel/PDF መላክ (ፈቃድ ካለ)።
- የእያንዳንዱ መዝገብ ረድፍ መጨረሻ ላይ ያለው **⋮** ምልክት የሚፈቀዱትን ድርጊቶች (ማየት፣ ማስተካከል፣ መሰረዝ) ያሳያል።
- የተሰረዘ መዝገብ ወደ **የተሰረዙ መዝገቦች** (Recycle bin) ይገባል፤ አስተዳዳሪ መመለስ ይችላል።
